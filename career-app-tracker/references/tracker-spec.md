# TSV 字段规范

## tracker.tsv 格式

Tab 分隔，UTF-8 编码。

### 字段

| 序号 | 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 1 | 日期 | 是 | YYYY-MM-DD | 2026-06-06 |
| 2 | 公司 | 是 | 全称 | XX科技有限公司 |
| 3 | 岗位 | 是 | 岗位名 | 运维实习生 |
| 4 | 城市 | 否 | 工作地 | 苏州 |
| 5 | 薪资范围 | 否 | k/月 | 4-6k |
| 6 | 平台 | 否 | 投递来源 | BOSS直聘 |
| 7 | 状态 | 是 | 见下方枚举 | 已投递 |
| 8 | 备注 | 否 | 自由文本 | 待回复 |

### 状态枚举

```
已投递 → 投递后初始状态
简历过筛 → HR 通知简历通过
笔试邀请 → 收到笔试通知
面试邀请 → 收到面试通知
一面 → 完成第一轮面试
二面 → 完成第二轮面试
HR面 → 完成HR面试
Offer → 收到录用通知
已接 → 接受 Offer
已拒 → 拒绝或主动放弃
被拒 → 被公司拒绝
无回复 → 超过 14 天无任何反馈
```
