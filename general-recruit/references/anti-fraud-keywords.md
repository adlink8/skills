# 求职诈骗识别素材库（通用版）

## 最高原则：付费一票否决

正规公司校招和实习招聘全流程 0 收费。**任何要求付费的"内推""保 offer""培训"都是诈骗。**

---

## 高危信号（命中任一 = 高度疑似诈骗）

### 付费类
- 收费内推 / 收费实习 / 付费培训 / 课程包 / 服务费 / 押金
- "不过退款""上岸后付费"
- 任何形式的转账要求

### 承诺类
- 保 offer / 保过 / 包录用 / 内部名额 / 绿色通道
- 免笔试 / 免面试 / 直推 / 直通车
- "100% 通过率""上岸率 XX%"

### 引流类
- 私信 / 加微信 / 扫码 / 进群 / QQ 群
- "主页找我""评论领取""DM 我"
- 伪装成避雷/踩坑分享引导去另一个人或群

### 伪装类
- "大厂在职导师 1v1 陪跑"
- "内部员工内推（收费）"
- "官方合作渠道"
- 模仿大厂 HR 账号名

---

## 中危信号

- 要求提供身份证照片/手持照
- 要求下载非主流 APP
- 面试全程文字聊天，不视频不电话
- "本岗位已经招满，但有个相似的……"

---

## 应对流程

1. 识别到高危信号 → 明确告知"这属于求职诈骗"
2. 中危信号 → 用"建议警惕"提醒
3. 统一提醒：
   - 正规招聘全流程 0 收费
   - 通过公司官网或正规招聘平台投递
   - 不要通过社交媒体私信或转账
4. 已付款 → 建议保留证据，在对应平台举报

---

## 警示模板

```
安全提醒：正规公司校招和实习全流程 0 收费。

- 任何收费内推/保过/课程包 = 诈骗
- 任何内部名额、绿色通道、免笔试承诺都不是正规流程
- 通过公司官网或正规招聘平台（BOSS直聘/智联/猎聘）投递
- 不要通过社交媒体私信或转账

如已付款，建议保留证据并尽快在对应平台举报。
```
