# GSD Generic Templates

Reusable templates for projects that use the Agent Documentation Architecture.

## Files

- `module-readme-template.md` — local module README template
- `project-doc-map-template.md` — project documentation map template
- `doc-audit-report-template.md` — documentation drift audit report template
- `agent-handoff-template.md` — handoff template for multi-agent execution

## Usage

Copy relevant templates into the target project's `.planning/templates/` or module directories. Keep templates factual and verification-oriented.
