# GSD Generic References

This directory contains shared references for the generic GSD skill suite.

## Files

- `agent-doc-architecture.md` — layered documentation architecture for GSD-compatible agents
- `doc-authority-order.md` — source-of-truth order when docs, code, tests, and state disagree
- `module-readme-protocol.md` — module README structure and usage rules
- `project-reading-order.md` — recommended reading order for project-level and module-level tasks
- `documentation-sync-rules.md` — when and how to update docs after implementation

## Core Principle

GSD controls project evolution. Module README controls local module understanding. Code implements behavior. Tests prove behavior. Intel and graphs make the project queryable. Docs audit prevents drift.
